Plove 全套服务端口与协作文档

1. 为什么有 4001、8088、4000 三个端口？

为了保障影视核心服务的安全与稳定，架构进行了职责解耦：

端口 服务角色 主要职责与访问场景
:4001 后端 API 中枢 核心 FastAPI 服务。所有影视数据拉取、缓存、爬虫规则接收都在这里。
:8088 智能爬虫控制台 用于开发、调试、测试单个站点爬虫脚本。隔离沙箱环境，防止测试崩溃影响主后端。
:4000 前端应用门户 Vue 3 界面。包含 / 播放主站以及 /_manage/sites 源站管理后台。

2. 后端 API 服务地址到底该怎么填写？

答案：直接填写 http://127.0.0.1:4001

在爬虫控制台 (:8088) 中，点击【推送到后端】弹窗时，系统需要知道把测试通过的 Python 脚本上传到哪台服务器。此时填入 http://127.0.0.1:4001 即可。

弹窗内部已经贴心增加了【填入默认后端 (http://127.0.0.1:4001)】快捷按钮，点击即可秒级填入，免去手动输入的烦恼。

3. 全链路协同工作流程

+-------------------------------------------------------+ | 1. 爬虫控制台 (:8088) 编写/导入 Python 脚本 | | - 执行全链路自动化体检 (首页/详情/直链) | | - 本地网络代理测试 (如 v2rayN 127.0.0.1:10809) | +--------------------------+----------------------------+ | | 点击【推送到后端】上传脚本 v +-------------------------------------------------------+ | 2. 后端服务中枢 (:4001) | | - 接收 POST /api/v1/admin/crawlers/upload 接口 | | - 自动持久化保存到 backend/crawlers 规则库 | | - 毫秒级热重载，无需重启整个服务 | +--------------------------+----------------------------+ | | 实时提供 API 数据 v +-------------------------------------------------------+ | 3. 前端应用 (:4000) | | - 访问 /_manage/sites 即可看到新增的影视站并开启 | | - 访问 / 用户端即可流畅检索和观看影视视频 | +-------------------------------------------------------+

4. 常用鉴权与 API 密钥说明

后端管理接口（如热重载、上传爬虫等）受令牌保护：

  • 请求头 Header 名称：X-Admin-Token
  • 配置方式：在 .env 中设置 PLOVE_ADMIN_TOKEN（必须使用高强度安全令牌）
  • 安全要求：严禁在生产环境公开默认令牌或使用弱口令
